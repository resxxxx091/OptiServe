# 错误码与连接类问题对照表

技术支持附表，配合 `SKILL.md` 使用。只在需要某个具体错误码的含义与排查方向时读取，不必逐条复述给用户。

本表只描述通用含义。禁止据此断言本次请求的真实根因，也禁止声称查阅过服务端日志——真实日志查询必须升级人工或二线技术。

## HTTP 状态码

| 错误码 | 含义 | 排查方向 | 需要补充的信息 |
| --- | --- | --- | --- |
| 401 | 认证失败 | 确认 Token/API Key 是否过期；确认请求时间戳与签名；确认账号登录状态 | 请求时间、使用的鉴权方式、Token 前几位（不要提供完整值） |
| 403 | 权限不足 | 确认账号或套餐权限；确认资源权限与 IP 白名单；确认接口是否已开通 | 账号类型、接口路径、出口 IP |
| 404 | 资源或路径不存在 | 确认接口路径与环境是否对应；确认资源标识是否正确 | 完整请求 URL（脱敏）、环境标识 |
| 500 | 服务端处理异常 | 记录 request_id 与发生时间；检查依赖服务、参数格式与服务端日志 | request_id、接口路径、请求参数摘要、响应体 |

状态码只说明失败发生在哪一层，不能单独判定是用户侧还是平台侧原因。

## 连接与超时

| 现象 | 常见原因 | 排查方向 | 需要补充的信息 |
| --- | --- | --- | --- |
| 连接超时 | 网络不通、DNS 解析失败、防火墙或代理拦截 | 从同一网络用最小请求复现；确认代理与证书配置 | 是否稳定复现、客户端所在网络环境 |
| 偶发超时 | 服务端限流、网络抖动、依赖服务响应慢 | 记录发生频率与请求峰值；重试必须带退避策略，不要无限重试 | 频率统计、并发量、超时发生的时段 |
| 证书或握手失败 | 证书过期、SNI/域名不匹配、中间人代理 | 确认是否经过企业代理；核对域名与证书有效期 | 完整报错文本、客户端系统时间 |

## Docker / Compose 部署

| 现象 | 排查方向 |
| --- | --- |
| 服务间调用失败 | 确认容器是否在同一网络；用服务名而不是容器 IP 访问 |
| 配置改了不生效 | 确认 volume 挂载路径，以及环境变量是否覆盖了配置文件里的值 |
| 端口不通 | 确认宿主机端口映射与容器内实际监听地址（`0.0.0.0` 而不是 `127.0.0.1`） |
| 启动即退出 | 先看容器日志与退出码，再判断是依赖未就绪还是配置错误 |
