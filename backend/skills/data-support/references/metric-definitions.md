# 指标口径对照表

数据分析附表，配合 `SKILL.md` 使用。只在需要向运营解释口径差异或回答"这个数怎么算的"时读取。

**本表不包含任何业务数值。** 表里的数字（阈值、时长）只有工具自己知道，这里只写口径定义。

## 指标 × 口径 × 常见误解

| 指标 | 数据源口径 | 运营常见的误解 |
| --- | --- | --- |
| GMV | 逐日订单金额合计 | 误以为是实际到账金额；未扣退款和运费 |
| 订单量 | 逐日订单数合计 | 误以为等于支付成功单量 |
| 访客数 | 逐日去重访客合计 | 误以为等于浏览量（PV） |
| 转化率 | 订单量 ÷ 访客数 | 误以为以支付成功为分子 |
| 退款率 | 逐日退款率算术平均 | 误以为按金额加权 |
| 库存 | 数据源快照值 | 误以为是实时值；演示数据不随真实交易变化 |

## 逐日明细的使用边界

- 逐日明细可以直接引用，但每个数字都要能对应到 `daily` 数组里的某一行。
- 涉及"对比期"的变化，只引用 `gmv_wow_change` 字段，不自行计算。
- 用户问的口径与数据源口径不一致时（比如要"支付口径 GMV"），明确说明口径差异，不要拿现有字段凑数。

## 归因表达

| 可以说 | 不可以说 |
| --- | --- |
| 转化率自 9 月 8 日起逐日下滑，累计降幅可从逐日明细算出 | 转化率下滑是因为竞品降价 |
| 退款率在正常区间内波动 | 退款率异常，需要立即整改 |
| 数据来自演示环境模拟数据源 | 这是你们店铺的真实经营数据 |
